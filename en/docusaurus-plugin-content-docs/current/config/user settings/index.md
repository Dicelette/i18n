---
title: Per user 
---
The command `/settings` allow to configure parameters for yourself, as a user (non-administrator).

It’s possible to configure :
- [Snippets](./snippets.md) : Reusable dices not tied to a character sheet or a model.
- [The link created by the contextual menu](../context_menu.md)
- [Attributes](./attributes.md) : A sub-system of statistics that can be used as shortcuts in roll formulas and that automatically resolve during the roll.
- [A custom formula](../custom_formula.md): A reusable Mathjs formula that automatically replaces a dice with this formula.
- [The prefix to edit the roll comments](./comment_prefix.md) : The prefix to use to edit the comment of a roll by replying to its result.

You can manage them on the dashboard.

The parameters are instantiated per server and per user, which means that each user can have their own parameters on each server.
